# AGENTS.md — Магазин металлоконструкций и решётчатого настила (Россия)

## Контекст задачи

Проектируем лендинг (герой-секцию и страницу) магазина, который продаёт **металлоконструкции и решётчатый настил** в России.

Заказчик прислал **два референса-картинки** (лежат рядом в этой папке):

- **Референс №1** — структура: крупное изображение справа, которое показано «этажами». Сверху этажи решётчатого настила, ниже — металлоконструкции, ниже — бытовки и т.д. (послойная/этажная структура продукта).
- **Референс №2** — герой-секция:
  - левая часть (цвет, шрифт, огранка слева в виде «кирпичей»/ступенчатая форма);
  - нижняя часть — товары, которые производит завод, в виде схем (графичных схем/breakdown);
  - правая часть — место под картинку.

## Задача / как должен выглядеть результат

Объединить два референса:

1. **Левая часть** — взять из референса №2: цвет, типографику, ступенчатую «кирпичную» огранку левого края.
2. **Правая часть** — взять изображение из референса №1: картинку «этажами» (решётчатый настил сверху → металлоконструкции → бытовки и ниже).
3. **Нижняя часть** — товары завода в виде графичных схем (как в референсе №2).

## Ключевая фича — интерактивный калькулятор

В герой-секции должен быть **калькулятор стоимости**:

- Когда пользователь нажимает/кликает на **элемент (часть) картинки** — этот элемент **подсвечивается** и проигрывается **анимация**.
- Анимация должна ощущаться как «деталь собирается / вращается / раскрывается» (предложить и реализовать самую подходящую: например вращение вокруг оси, разъединение/сборка слоёв, раскрытие элементов, и т.п.).
- По выбранному элементу (части) показать **приблизительный подсчёт стоимости**.
- По уточнению пользователя калькулятор работает только с одним выбранным изделием. У каждой категории собственные параметры и спецификация; суммирование разных категорий удалено.

## Что нужно от модели (чек-лист)

1. **Посмотреть на оба референса** в папке (прочитать картинки), разобрать:
   - точные цвета, шрифты, отступы левой части (реф. №2);
   - «кирпичную»/ступенчатую огранку левого края;
   - структуру «этажей» и композицию правого изображения (реф. №1);
   - разметку схем нижней части с товарами.
2. Написать **HTML/CSS/JS** (или выбранный стек, в т.ч. SVG для схем и картинки-этажей) лендинга.
3. Реализовать **интерактивную картинку-этажи**: каждый этаж/слой — отдельный кликабельный элемент (SVG-слой или изображение с hotzone'ами).
4. Реализовать **анимацию подсветки/сборки** при клике на элемент.
5. Реализовать **калькулятор**: выбор элементов → подсчёт приблизительной стоимости → итоговая сумма и список.
6. Адаптивность, кроссбраузерность, российская локализация (рубли ₽, русский язык, ЕСКД-стиль при желании).

## Требования к контенту и стилю

- Язык интерфейса — **русский**.
- Валюта — **рубли (₽)**.
- Товары/слои (примерный набор, уточнить по референсам):
  - решётчатый настил (верхний этаж);
  - металлоконструкции (средние этажи);
  - бытовки (нижняя часть);
  - и прочее, что увидим на референсе.
- Нижние «схемы» продукции — графичные (SVG), в духе инженерных схем завода.
