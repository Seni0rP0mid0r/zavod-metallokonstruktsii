## Исключено из публикации

- Логотипы, иконки, технические заглушки и сторонние изображения.
- Пять ссылок в исходных слайдерах очистных сооружений возвращают HTTP 404; локальная версия использует 48 доступных оригиналов из 53 заявленных изображений.
- Вентиляция остаётся без проектной галереи до появления подтверждённого материала.
- Структура всех 15 подтверждённых групп содержится в `js/project-archive.js`; архивный манифест сохраняет исходный URL для каждого файла.
