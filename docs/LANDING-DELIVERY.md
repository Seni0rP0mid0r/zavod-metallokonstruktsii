# Лендинг ЭТАЛОН — обновление 2 сентября 2026

Запуск: `node server.cjs`, адрес http://localhost:4173/.

Главная: два desktop-экрана с учётом sticky-шапки, индивидуальный калькулятор, семь схем продукции, галерея трёх сгенерированных визуализаций, компания и инженерная подготовка, 11 уникальных логотипов партнёров, контактная форма.

18 внутренних разделов открываются через page.html?slug=...; содержание хранится в pages-data.js. Навигация и общие взаимодействия — site.js, визуальные дополнения — site.css.

Формы — согласованная заглушка. Ничего не отправляют и не сохраняют. Коммерческие ставки демонстрационные. Контакты, реальные кейсы и почтовая интеграция ожидают исходных данных.

Проверено: синтаксис JS, calculator.test.cjs, ссылки всех 18 разделов; браузерные проверки 1440×900, 1280×720 и 390×844; переключение категории, галереи, мобильного меню и отправка тестовой демо-формы. Горизонтального переполнения на проверенных размерах не обнаружено. На телефонах секции имеют естественную высоту для читаемости.

Impeccable применён для init, компоновки и визуальной проверки. Автоматический detector работал в degraded-режиме без HTML parser: не является полной проверкой доступности. Сохранена исходная типографика по направлению проекта.

Оригиналы логотипов скопированы без изменений. Партнёрские логотипы показаны CSS-фрагментами предоставленных скриншотов; повтор Газпрома убран. Два неподписанных знака не получили вымышленных названий.
