# Обновление по трём новым референсам

## Визуальная часть
Левая панель: фактура терракотового бетона с рельефной кирпичной кромкой, пересозданная imagegen из первого нового референса. Текст и кнопки — HTML. Заголовок намеренно повторяет четырёхстрочную композицию пользователя. Шапка повторяет цветовое деление, светлую марку и навигационную композицию второго референса; sticky, фиксированная высота без скачка документа, мобильное меню.

Этажи пересозданы встроенным imagegen по третьему референсу. Файлы assets/terracotta-panel.png и assets/industrial-stack-v2.png. Маски CSS отделяют этажи для независимой анимации. Основание масштабировано к ширине остальных модулей. При выборе один этаж выдвигается, остальные слегка отступают. Повторный клик сохраняет выбор.

## Расчёт
Только одна активная категория. Параметры сохраняются в памяти страницы при переключении; обновление страницы возвращает начальные значения. Нет общей корзины из разных категорий.

- Настил: длина, ширина, ячейка, несущая полоса, покрытие, количество.
- Каркас: масса, сталь, сложность изготовления, покрытие, КМД, количество.
- Бытовка: размер, утепление, отделка, электрика, окна, количество.
- Очистное сооружение: объём, материал, технология, насосы, автоматика, количество.

Все ставки и коэффициенты демонстрационные, не подтверждены прайсом. Это интерфейс предварительной оценки, не инженерный расчёт прочности или подбор технологии очистки. Формулы в calculator.js; стоимость разбита на составляющие; недопустимые поля блокируют итог и спецификацию.

## Движение
Нативная плавная прокрутка по ссылкам учитывает высоту sticky-шапки. Смена категории не прокручивает страницу и не меняет число полей. Плавные CSS-переходы модели, GSAP-появление нижних блоков. Исключён прежний ScrollTrigger pin, способный менять поток документа. Учитывается prefers-reduced-motion.

## Промпты imagegen
Панель: preserve precisely terracotta rough concrete texture, left brick column with chipped edges and dark seams from the reference; remove all text, logos, buttons, phone and stamp, keep only background texture.

Этажи: recreate the reference industrial exploded stack faithfully; four separated isometric modules with identical width and square footprint, silver grating, steel truss frame, terracotta cabin, rust concrete treatment basin; near-black background, no labels; portrait 1024x1536.
