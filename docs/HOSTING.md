# Размещение на хостинге

Сайт состоит из статических HTML, CSS, JavaScript и локальных изображений. PHP, база данных, npm-зависимости и Node.js на хостинге не нужны.

## Пакет для загрузки

В корне проекта выполните `node scripts/package-site.cjs`. Скрипт копирует публичные файлы в `dist/`: `index.html`, `page.html`, `css/`, `js/`, `assets/` и `.nojekyll`. Исходники тестов, документация, служебные каталоги и секреты не входят в пакет. Для чистого релиза используйте свежий checkout: скрипт не удаляет устаревшие файлы из существующего `dist/`.

Загрузите содержимое `dist/` в корень домена (`public_html`, `httpdocs` или каталог, указанный хостингом). На GitHub Pages публикуется тот же набор файлов. Все ссылки на ресурсы относительные, поэтому сайт можно разместить и в подкаталоге.

## Настройки

- Главный документ: `index.html`.
- Внутренние страницы: `page.html?slug=...`; сохраняйте query string при перенаправлениях.
- Включите HTTPS и перенаправление HTTP на HTTPS в панели хостинга.
- Для HTML установите `Cache-Control: no-cache`; для CSS и JS используйте короткий срок кеша или обязательную проверку свежести, поскольку имена ресурсов не содержат хеш версии.
- Включите Brotli или gzip, если хостинг поддерживает.
- Не загружайте корень репозитория целиком: публичным должен быть только пакет `dist/`.

## Заявки и расчёт

Формы открывают подготовленное письмо через `mailto:sales@etalonorg.ru`. Пользователь проверяет письмо и отправляет его в своей почтовой программе. Сайт не заявляет об успешной отправке. Если почтовая программа не настроена, доступны прямой адрес и телефон. Для серверной отправки в будущем потребуется отдельный обработчик, защита от спама и проверка доставки.

Калькулятор показывает предварительный ориентир, а не коммерческое предложение. Подтверждённый производителем прайс в проект не предоставлялся; перед использованием калькулятора как коммерческого инструмента ставки в `js/calculator.js` необходимо согласовать. Окончательные условия определяются спецификацией.

## Проверка после переноса

Откройте главную и внутреннюю страницу по прямому адресу. Проверьте изображения, меню, калькулятор, просмотр фото, телефон и подготовку письма. На мобильном проверьте отсутствие горизонтального скролла. Подтвердите, что опубликованная версия совпадает с commit релиза, и проверьте консоль браузера на ошибки.
