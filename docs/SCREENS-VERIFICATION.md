# Изменение экранов и каталога

Первый экран ограничен высотой окна на десктопе: 88px sticky-шапки + calc(100svh - 88px) героя. На 1440×900 начало следующего экрана = 900px, на 1280×720 = 720px. На телефоне применяется последовательная компоновка с читаемым текстом вместо фиксированной высоты.

Новые чертежи: assets/catalog-pressed.svg, catalog-welded.svg, catalog-frame.svg, catalog-cabin.svg, catalog-water.svg, catalog-doors.svg, catalog-ventilation.svg. Это концептуальные схемы, не рабочая документация.

Категории соответствуют предоставленному пользователем каталогу https://etalonrussia.ru/. Страница прессованного настила https://etalonrussia.ru/pressovannyj-nastil/ дополнительно проверена: описывает габариты панелей до 3000×2000 мм. В демонстрационном конфигураторе установлен этот диапазон; нестандартные размеры обсуждаются с менеджером.

Форма заявки — согласованная пользователем заглушка. Не вызывает сетевых запросов, не сохраняет контакты в localStorage или файлы, не показывает ложное сообщение об отправке. После проверки полей показывает, что заявка подготовлена, но письмо не отправлено. Для проверки использованы только вымышленные тестовые контакты.

Проверено: формулы всех шести категорий, варианты параметров и числовые границы, отдельные значения для прессованного настила/дверей/вентиляции; браузерное переключение каталога и формы; первый экран десктопа, мобильная версия.

Impeccable detector запущен один раз: DEGRADED, HTML/CSS-парсеры отсутствуют. Указанная неиспользуемая картинка удалена вместе со старым диалогом продукции; замечание к Geist не применено, так как в этой задаче сохраняется действующая типографическая система. Визуальная проверка выполнена отдельно в браузере.
